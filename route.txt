================================================================================
BoostBuddy MVP - Application Routes with Role-Based Access
================================================================================
Base URL (development): http://localhost:3400
Framework: Next.js 16 (App Router)

User Roles: ADMIN, CLIENT, EMPLOYEE
Access Legend:
  [PUBLIC]     = No authentication required
  [ADMIN]      = Admin only
  [CLIENT]     = Client only
  [EMPLOYEE]   = Employee only
  [AUTH]       = Any authenticated user (Admin / Client / Employee)
  [SYSTEM]     = Backend only (webhooks / OAuth callbacks, not for users)

The 7 shared [AUTH] routes are: /checkout, /logout, /api/logout,
/api/user/credits, /wallet, /wallet/top-up, /wallet/transactions
(GET 6, POST 1 = /api/logout).

The 2 [SYSTEM] routes are called by external services (Supabase / Stripe),
not by logged-in users, and are not counted toward any user role.

POST routes (only 2 in the whole app):
  1. /api/logout           [AUTH]   - handled by logout API
  2. /api/webhooks/stripe  [SYSTEM] - called by Stripe

ADMIN SIDEBAR MAPPING (collapsible grouped structure)
================================================================================
Sidebar behavior:
  - Single-link entries: always visible (Dashboard, Client Registry, Box
    Inventory, Notifications)
  - Collapsible groups: COLLAPSED BY DEFAULT. The group containing the
    current route auto-expands; others stay collapsed until clicked.
  - Click a group header to toggle expand/collapse. User toggles persist
    for the session; navigation auto-opens the destination group.
